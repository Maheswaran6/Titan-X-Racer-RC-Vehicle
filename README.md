# TITAN-X RACER Smart Multi-Terrain Wireless RC Vehicle

This project is a smart wireless RC vehicle designed for multi-terrain operation using joystick control.

## Features
- Wireless joystick control
- Multi-terrain movement
- Camera live monitoring
- Voice control
- LED lighting effects
- Smoke generation unit
- Turbo speed mode

## Components Used
- DC Motor
- ESC
- Servo Motor
- Lithium-ion Battery
- Receiver Unit
- Joystick Controller

## Applications
- Surveillance
- Robotics
- Smart vehicle systems
- Research and learning
